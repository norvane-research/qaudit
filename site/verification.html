Vérifier une attestation

Chaque attestation émise est inscrite ici avec l'empreinte SHA-256 du fichier de trades audité. Saisissez la référence (AUD-AAAA-NNN) ; si vous détenez le fichier d'origine, son empreinte doit correspondre exactement. Aucune donnée personnelle n'est publiée.

Calculer l'empreinte d'un fichier : certutil -hashfile fichier.html SHA256 (Windows) · shasum -a 256 fichier.html (macOS/Linux).
